# Hall's Plumbing, LLC — project record

**Live at https://hallsplumbingllc.com** since 23 September 2026.
Built by Hot Diggity Digital for Jerry Hall.

Plain HTML, CSS and one small script. No build step, no framework, no database,
no API keys. That is deliberate — it means this site has almost nothing that can
break, and anyone can pick it up.

## Where it lives

| | |
|---|---|
| **Source** | GitHub `flopjunkie/halls-plumbing-llc`, branch `main` |
| **Hosting** | Cloudflare Pages project `halls-plumbing-llc`, free plan, **Josh's** account |
| **Domain** | GoDaddy, registered to **Jerry**. Renews 13 Jan 2028 |
| **Also serves** | `www.hallsplumbingllc.com` and `halls-plumbing-llc.pages.dev` |

**Pushing to `main` deploys automatically.** Do not upload files by hand.
Cloudflare keeps every past deployment on its own URL, so rolling back is
picking an older one from the Deployments list.

## Brand colours — do not change these

Sampled pixel-by-pixel from Jerry's own logo. Jerry confirmed navy and silver.

| | Hex | |
|---|---|---|
| navy | `#131A2B` | the logo background |
| silver | `#C3C2C4` | the lettering |
| sky | `#91BDEA` | the bar under the wordmark — accent only |

Every other shade in `styles.css` is a step built around those three. Add a new
step if you need one; do not retune the anchors.
